# Roadmap

## 0.1 - Discovery

Read-only.

- Detect Zabbix version
- Inventory installed templates
- Read template UUID
- Read vendor
- Read vendor version
- Identify official templates
- Build upstream repository index
- Detect update availability
- Display native Zabbix interface

## 0.2 - Comparison

Read-only.

- Export installed templates
- Use configuration.importcompare
- Granular comparison
- Detect local modifications
- Detect conflicts
- Host impact analysis
- Risk classification

## 0.3 - Update

Write operations introduced.

- Backup before update
- Review changes
- Confirmation workflow
- Template import/update
- Validation
- Update history
- Rollback

## 0.4 - Repository providers

- GitHub
- GitLab
- Community templates
- Private repositories
- Custom templates

## 1.0

Stable release.
